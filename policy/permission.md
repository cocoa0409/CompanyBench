# Molly Digital 权限规范

## 事务说明

| 事务 | 说明 |
|------|------|
| 客户 | 客户账户资料、会员等级与消费记录 |
| 订单 | 订单创建、状态流转、取消操作 |
| 产品 | 产品目录、价格、库存、特价信息 |
| 制造商 | 制造商基本信息与联系方式 |
| 付款 | 支付方式选择、转账确认、收款核实 |
| 配送 | 物流状态查询、确认收货 |
| 退款 | 退货申请、仓库验货、退款执行 |
| 工单 | 客户工单创建、分配、处理与回复 |
| 邮件 | 企业邮箱收发与历史查询 |
| 文档 | Internal / External 类型文档的创建与查阅 |
| 日程 | 个人及团队日历事件管理 |
| 职位 | 岗位描述（JD）发布、更新与招聘流程统计 |
| 候选人 | 候选人档案、投递记录与简历管理 |
| 申请 | 假勤申请与内部资源申请的提交 |
| 面试 | 面试日程安排与面试评分记录 |
| OKR | 季度目标设定、Review 提交与绩效评级 |
| 员工 | 员工基本信息（姓名、职位、联系方式）与部门记录 |
| 假勤 | 年假、病假、事假余额与休假记录 |
| 审批 | 假勤审批与资源审批的审批操作 |
| 薪资 | 薪资结构、月薪明细与年终奖计算 |
| 公开政策 | 企业基本信息、企业概览、客户与订单管理规范 |
| 管理政策 | 组织架构、招聘规范、员工管理规范、权限规范 |
